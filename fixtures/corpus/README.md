# Synthetic corpus

R2 includes three original synthetic PDF test fixtures:

- `r2-policy.pdf`: one fictional policy sentence, generated by `backend/tests/pdf_fixture.py`.
- `r2-encrypted.pdf` and `r2-encrypted-empty.pdf`: synthetic ReportLab-generated
  encryption rejection specimens, with nonempty and empty user passwords respectively.
  Their test-only owner password is `fixture-owner`; the nonempty user password is
  `fixture-only`. Regeneration is not needed to run tests, and ReportLab is not a
  project dependency.

Later milestones will add a versioned evaluation corpus manifest here.
Do not use real organizational secrets. The blueprint requires English/Nepali,
confusable titles across tenants, restricted collections, source replacements,
conflicts and an inert prompt-injection specimen. No evaluation corpus is seeded yet.
